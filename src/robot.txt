# IHC
## Bot de Estoque Inteligente 🤖

Agente conversacional integrado ao **Telegram**, com suporte a **voz**, que traduz perguntas em linguagem natural para consultas **SQL** utilizando **Chain-of-Thought (CoT)**, consultando um banco de dados de estoque através de uma API própria.

---

## 📌 Descrição

Este projeto implementa um pipeline completo de **Text2SQL**, permitindo que o usuário faça perguntas em linguagem natural (via texto ou voz) e receba respostas baseadas em dados reais de um banco de estoque, sem precisar escrever SQL manualmente.

## LÓGICA DE ESTRUTURA EXEMPLO:

bot.py
        Contains the Telegram bot logic
        Loads a local LLM via DSPy
        Defines the SQL-generation pipeline and safety checks
        Includes a GEPA training setup for improving SQL generation quality
        Handles both text and voice messages
    server.py
        Starts a FastAPI app
        Creates the SQLite database if needed
        Exposes an endpoint at / that accepts a question and calls the bot logic
    sql_generator_optimized.json
        Saved trained DSPy model artifact used to generate better SQL prompts
    lojas.db
        Runtime database with product inventory data, with fields like produto, preco, departamento, data_fabricacao, and data_validade
